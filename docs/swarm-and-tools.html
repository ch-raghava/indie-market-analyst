Extendability

Swarm & Tools

Define teams as configuration and extend capabilities with a few lines of Python. No need to touch the core orchestration engine.

Config

Teams as YAML

Located in config/swarm/*.yaml, you can declare specialized agents and their handoff logic.

name: "equity_research"
agents:
  - name: "collector"
    role: "Data Collector"
    tools: ["yfinance_tool", "news_tool"]
  - name: "verifier"
    role: "Data Verifier"
    handoff: "calculator"
  - name: "calculator"
    role: "Technical Calculator"
Registry

The Reflection Registry

To add a new tool, simply drop a Python module into indie_market_analyst/tools/. The system automatically discovers it.

# indie_market_analyst/tools/custom_tool.py
from typing import Annotated

def fetch_alpha_signals(ticker: str) -> str:
    """Fetches custom alpha signals for a given ticker."""
    return f"Alpha signal for {ticker}: 0.85"

TOOLS = [fetch_alpha_signals]
Skills

Ephemeral Skills

Skills are specialized prompt fragments and tool allowlists stored in skills/. They give agents a temporal identity without hardcoding roles.

Check the SKILL.md in any skill folder to see how prompts are structured and what tools they are allowed to access.
