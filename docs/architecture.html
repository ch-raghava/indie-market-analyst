System Design

Architecture

Indie-market-analyst operates on two distinct planes: a cognitive engine managing agents and a deterministic engine providing precise data processing.

01

The Cognitive Engine

Located in indie_market_analyst/, this layer is responsible for agent orchestration, tool selection, and memory management. It uses the OpenAI Agents SDK to manage swarms of specialized agents (collector, verifier, calculator) that communicate via strict Pydantic schemas.

02

The Deterministic Engine

Located in backtest/, this is pure Python (pandas/numpy). It never calls an LLM. It provides ground-truth calculations for technical indicators, portfolio metrics, and the Indian cost model. Agents call into this engine via tools, but the engine itself remains blissfully unaware of the AI layer.

Data Flow
  1. User sends a natural language query via SSE.
  2. Orchestrator identifies the intent and selects a Swarm Team.
  3. Agents within the team execute Tool Calls against the deterministic engine or public APIs.
  4. Results are verified for source and recency by a dedicated Verifier Agent.
  5. A final Pydantic-typed note is synthesized and streamed back to the UI.
